# 下课整理（P3）规范

这是学习台「下课」按钮触发的**整理任务**，不是普通提问。触发后请按本规范操作，完成后在回复最后加 `<!-- study-desk:class-end:<classId> -->`（classId 由触发消息给出）。

## 输入

- `PDF`：触发消息里的路径（相对工作区），就是这节课打开的 PDF。
- `sidecar`：`<PDF>.annotations.json`，里面是这节课的标注（页码、选区/框选坐标、quote、question）。
- 对话：当前会话里每条提问的用户消息带 `<!-- study-desk:<id> -->`，紧随其后的 assistant 文本就是回答；按 id 与 sidecar 对应。
- 一份文件只做一次下课；若 sidecar 已有 `classEndedAt`，不要重复整理。

## 输出

1. **原版 PDF 不动**：不要覆盖、不要移动原版；学习台里的原版始终可读。
2. **批注版 PDF**：写到 `<原 PDF 去掉 .pdf>-批注版.pdf`（同一目录）；只在批注版上叠加，原页全部保留，最后追加一页总结；不要覆盖原版。
3. **最后一页课堂成果总结**：原 PDF 的**全部页面都保留**，总结页**追加在批注版最后**（原页数 + 1）；实现时用 `pages=-` 或动态读取页数，不要写死页数。一页，套用下方固定版式。
4. **sidecar**：在原版 sidecar 写 `"classEndedAt"` 和 `"annotatedPath"`（批注版相对路径）；再把这份 sidecar 复制到 `<批注版>.annotations.json`，加 `"originalPath"`（原版相对路径）。这样原版/批注版都能切换和继续提问。

## 批注怎么加（模仿真实听课笔记）

- **选中文字**：在原选区上做半透明高亮；**必须用透明填充（约 15%–20% opacity）**，不能用不透明的浅色块盖住文字；也可以改用下划线/边框。在高亮旁边（优先右侧/下方，避开正文）放一个便签/文字框，内容是「问题 + 回答要点」，字要小、可读，不要盖住原内容。
- **框选截图**：在截取区域的旁边（优先右侧）放便签，内容同样是「问题 + 回答要点」；不要把截图缩略图另外贴一页。
- **通用提问**（没有选区/截图）：放在该页页边空白处（优先右上角/右下角）。
- **用户上传的图片**（手写作答、草稿、题目照片）：也要贴到对应页/总结页的“我的作答”位置；先旋转/缩放，不要覆盖原题；和 PDF 原题重复的截图可以不重复贴，优先贴手写/草稿。
- **不加编号**，不画连线，不做目录页；批注本身就像你上课随手写的边注。
- 回答只放**要点/纠错**，不要整段复制对话；完整回答留在聊天里。
- 页面没有空白时**不要硬塞**：优先放页边/标题旁的空白；实在没有，就把这一点放进最后一页总结，宁可不放也不要压住原内容。
- 放便签前先跑 `node study-desk-build/end-class-layout.mjs <原始PDF>`，只在它返回的 `free` 矩形里放（宽高要够）；放不下就进总结页。footer/header 已被排除。
- 颜色用与课件协调的强调色（红/赭），保证黑白打印也能看清；不要改动原页面的文字、排版和页数顺序。

## 最后一页：课堂成果总结（固定版式，一页）

- 页面尺寸、方向、字体气质**跟随原 PDF**（原文件是 16:9 幻灯片就用 16:9；A4 就用 A4）；不要另起一套完全不同的视觉。
- 标题：`第 N 次课 · <课程名>`；副标题：`课堂成果总结`。
- 元信息一行：日期、页码数、问答数（可选，不要太多）。
- **本课卡住的点 / 易错点**：3–5 条，优先选对话里用户答错、反复问、明显没懂的地方；每条写成「问题 → 正确思路」，公式用 LaTeX 排版。
- **待复习**：1–3 条，写具体动作（例如“重做第 8 页例 2”“把 1^∞ 型的配平再推一遍”）。
- **不要**再罗列整节课的通用知识点——那些原课件里已经有；这一页只服务于“我哪里没掌握”。
- 固定页脚：`高等数学（上册·同济第八版） · 第 N 次课` + 页码。
- 内容多时压缩取舍，**保证一页**，不续页。

## 实现建议

- 用仓库里已有的 LaTeX 工具链（`tools/bundle`、`tools/slides`）做 `pdfpages` + TikZ 叠加：原页用 `\includepdf` 原样嵌入，批注用 TikZ 画在对应坐标上，最后加一页总结；编译后页数与页面尺寸保持原样。
- 或者用 Python（PyMuPDF）在原 PDF 的副本上写 highlight/text box，再用同一个 LaTeX 模板生成总结页合并。两种都可以，关键是**原页面不被重排**。
- 坐标：sidecar 里 rect 是归一化值（0–1），乘以页面宽高即可；注意 PDF 坐标原点在左下，屏幕/TikZ 原点在左上，换算时翻转 y。
- 完成后自检：
  - 原文件备份存在；原路径的 PDF 是批注版；
  - 页数 = 原页数 + 1；最后一页是总结；
  - sidecar 有 `classEndedAt`；
  - 回复最后有 class-end 标记。

## 不要做

- 不要覆盖/删除备份文件夹里的原文件；
- 不要改 sidecar 里已有的标注（除了加 `classEndedAt`）；
- 不要给批注编号、不要做目录页；
- 不要在总结页写大段泛泛的“本课重点”。
